Gradle is a build automation tool that is used to build, test, and package applications. It is an open-source project and is available for multiple programming languages.

Gradle project structure:

my-project/
├── build.gradle  ---> Main Gradle build script, it contains all the configurations for the project
├── settings.gradle  ---> Multi-project settings (if needed)
├── gradlew      ---> Wrapper script for running Gradle commands (mac/linux)
├── gradlew.bat  ---> Wrapper script for running Gradle commands on Windows
├── gradle/      ---> Wrapper files (keeps Gradle version info)
    ├── wrapper/
├── src/         ---> Source code directory
│   ├── main/
│   │   ├── java/   ---> Your java source code
│   │   └── resources/   ---> configs, properties, static files
│   └── test/
│       ├── java/   ---> Your java test code
│       └── resources/   ---> test related configs/resources
├── gradle.properties  ---> Properties file for Gradle
├── gradlew.bat  ---> Wrapper script for running Gradle commands on Windows

Gradle Commands:

- gradle build  ---> Builds the project and generates the JAR file
- gradle clean  ---> Cleans the project by removing the build directory
- gradle run  ---> Runs the application
- gradle test  ---> Runs the tests
- gradle jar  ---> Creates a JAR file
- gradle build -x test  ---> Builds the project without running the tests
- gradle build -x test -x jar  ---> Builds the project without running the tests or creating a JAR file
- gradlew.bat run  ---> Runs the application on Windows even if gradle is not installed


What is Gradle wrapper?

Gradle wrapper is a set of scripts + small JAR files that allow you to run Gradle without having to install Gradle on your machine. It is a single file that contains all the necessary information to run Gradle.
