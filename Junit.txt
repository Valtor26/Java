Junit is a testing framework for Java. It is used to write and execute tests for Java applications.


Assertions: comparing actual and expected values

assertEquals(expected, actual): 
- Checks if two objects are equal
- If not, it throws an AssertionError


assertEquals(expected,actual,"message"):
- Checks if two objects are equal
- If not, it throws an AssertionError with the given message  
- the message is evaluated for both success and failure


assertEquals(expected,actual,()->"message"): Supplier functional interface
- Checks if two objects are equal
- Success: if they are equal without checking the message
- If not, it throws an AssertionError with the given message, the message is evaluated only for failure
- The message is generated by the lambda expression


assertNotEquals(expected,actual): Reverse of assertEquals
- Checks if two objects are not equal
- If they are equal, it throws an AssertionError

Junit Annotations:

@Test: 
- Marks a method as a test method.
- Visibility: public, protected default
- Also informs test engine what method needs to run
- It only checks for failure, the default result is always success
